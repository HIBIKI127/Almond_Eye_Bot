按关键词选择，资料相互隔离

长句包含关键词即可触发，英文字母不区分大小写。多个库同时命中时，选择匹配关键词最长的库；长度相同时选择最早创建的库。只检索所选库，最多携带 4 段资料，不发送整个库。资料不足时模型会被要求明确说明。启用的资料库优先于固定关键词规则，继续遵守群开关、回复率、AI 开关、冷却及限额。命中的资料片段会随聊天发送至项目配置的模型 API。

原文件保存在项目 uploads/knowledge/，配置和可检索文本保存在数据库中；SQL 导出包含资料文本，恢复后无需原文件也能检索。资料库是所有已允许聊天共用的参考资料，请勿导入不适合向这些用户提供的内容。
